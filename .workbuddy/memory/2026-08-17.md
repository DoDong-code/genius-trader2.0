## 真机 BUG1：iOS 登录页输入内容不可见（11:42 本轮，仅 login.wxss）

### 根因
- `login.wxss .field-input` 上一轮为「锁文字色」加了 `-webkit-text-fill-color: var(--text-primary)`
- `-webkit-text-fill-color` 是 WebKit 私有属性，微信**原生 input 组件**在 iOS WKWebView 上解析 CSS 变量 `var(--text-primary)` 会失效 → 文字渲染为透明/不绘制
- 开发者工具用 Chromium 内核能正常解析 → 工具正常；iPhone 15 Pro 真机（WKWebView + 原生 input）异常 → 内容不可见但值存在、可正常登录

### 修复（login.wxss + register.wxss 的 .field-input，共 2 处）
- 移除 `-webkit-text-fill-color`；`color` 改硬编码 `#1a1a1a`（等于 --text-primary）；加 `caret-color: #1a1a1a`
- login.wxss（11:42）+ register.wxss（11:45 用户确认后一并修）均已修；全项目已无 `-webkit-text-fill-color:` 属性
- **未改** login.js/register.js/wxml、app.js、后端、网页端

### 教训（写入 MEMORY.md 微信小程序坑）
- 小程序原生 input 在 iOS 真机**禁用 -webkit-text-fill-color + CSS 变量**；文字色用硬编码 color 最稳
