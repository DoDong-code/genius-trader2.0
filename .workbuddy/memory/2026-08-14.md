## 云服务适配 + 养基宝扫码登录修复（mp1 小程序）
- 诊断：①「未开启云端」是因为 `app.globalData.cloudReady` 为 false（`utils/request.js` 的 `initCloud()` 在未开通云开发/未创建云环境时返回 `ready:false`）→ 登录退化为本机 mock（`_mockLogin`），故显示「本机已授权（未开启云端）」。真正"开通云环境"是微信开发者工具/公众平台的控制台操作（无法用代码点按钮），但项目已配真实 AppID `wx51fdde35e48c4344` + `cloudfunctionRoot`，代码用 `wx.cloud.DYNAMIC_CURRENT_ENV` 正确。
- ② 养基宝扫码刷不出二维码：根因是后端 `/api/provider/yangjibao/qrcode` 返回的是 `qr_url`（要编码进二维码的内容），网页端用 `https://api.qrserver.com/v1/create-qr-code/?size=240x240&data=ENCODED(qr_url)` 现生成二维码图片；而小程序旧代码把 `qr_url` 直接当图片 url 传给 `wx.previewImage`，永远加载不出。网页端功能正常佐证后端 OK，纯客户端 bug。
- 改动：
  - `pages/setting/setting.js`：`onWechatLogin` 改为先 `app.enableCloudSync()`（自适配，环境就绪即真身份，失败回退本机），不再依赖启动快照 `cloudReady`；`_mockLogin` 增加 `cloudUnavailable` 参数，云端不可用时弹 modal 说明需在开发者工具开通云开发；新增 `fetchYjbQrcode`（内联生成 qrserver 图片）/ `_startQrPoll`（每 2s 轮询 `/status?qr_id=` 最长 90s，confirmed 自动刷新状态并收起）/ `_stopQrPoll` / `closeYjbQr` / `onUnload`/`onHide` 清理计时器；data 加 `yjbQrShow/yjbQrUrl/yjbQrStatus/yjbQrId` 与 `cloudReady`。
  - `pages/setting/setting.wxml`：养基宝未登录区改为「扫码登录按钮 ⇄ 内联二维码面板（图片+提示+刷新/关闭）」；备份分组新增 `wx:if="{{!cloudReady}}"` 的云环境未检测提示。
  - `pages/setting/setting.wxss`：新增 `.wx-qr-box/.wx-qr-img-wrap/.wx-qr-img/.wx-qr-placeholder/.wx-qr-tip/.wx-qr-actions` 样式。
- 校验：node --check 通过；setting.wxml 标签平衡、setting.wxss 括号均 OK。
- 待用户手动：在微信开发者工具开通「云开发」并创建环境（之后 `cloudReady` 自动 true，登录即真身份）；正式发布需把 `api.qrserver.com` 加入小程序后台 request 与 downloadFile 合法域名（开发期 `project.config.json` 已 `urlCheck:false` 不受影响）。
