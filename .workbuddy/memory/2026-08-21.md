- 根因定位（所有 git 怪问题的真正源头）= 仓库父目录 `Codex3 基金` 含中文+空格：① `git -C <CJK path>` 无法 chdir（"cannot change to ... No such file or directory"），必须用 bash 内建 `cd`；② `git fetch`/`git update-ref` 无法持久化 `refs/remotes/origin/*`（packed-refs 空、目录缺失，update-ref 报 rc=0 却不落盘）；③ 沙箱对新目录的 `git clone` 有 FS 隔离，clone 不落盘。
