# Genius Trader 小程序设计规范（mp1）

> 提取自 `app.wxss` / 各页面 wxss / 组件 wxss / `app.json` / `app.js`，以 rpx 为单位（默认 750rpx = 屏幕宽）。
> 设计语言：Apple 风内容页（大圆角白卡 + 中性色）+ 微信 WeUI 风设置页（灰底分组 cell）。

## 8. 设置页图标（WeUI cell 前置图标）
- 采用 **线条风格 SVG** 图标，位于 `mp1/images/icons/`
- 图标尺寸：`32rpx × 32rpx`，置于 `56rpx × 56rpx` 彩色圆角底上
- 数据源 `datasource.svg`（蓝）、AI `ai.svg`（紫）、策略 `strategy.svg`（橙）、同步 `sync.svg`（绿）、备份 `backup.svg`（蓝）、危险 `danger.svg`（红）
- 不再使用 emoji/彩色填充图标

## 10. 安全距离（Safe Area）
- **状态栏高度**：`app.globalData.statusBarHeight`（运行时取自 `wx.getWindowInfo()`，默认 `20px`）
- **导航栏高度**：`navBarHeight = 44px = 88rpx`（固定）
- **顶部占位**：首页 `.topbar` 与 `.container` 均设置
  - `padding-top: {{statusBarHeight}}px`
  - `height: {{statusBarHeight + navBarHeight}}px`
  - 设置页顶部为纯白 `.topbar`（`#ffffff`，无标题，与账号栏融合）
- **底部安全**：统一用 `env(safe-area-inset-bottom)`
  - 自定义 tabBar `.tab-bar`：`padding-bottom: env(safe-area-inset-bottom)`（高度 `100rpx` + 安全区）
  - 弹窗内容：如上 `calc(... + env(safe-area-inset-bottom))`
  - 页面容器：`.container` 底部 `48rpx`（内容页已各自避开 tabBar 高度）

## 12. 统一规则（已落地约束）
1. **按钮无边框**：所有 `.btn` 及 `button::after { border:none }`；设置页/组件各自再写一份（样式隔离）。
2. **按钮高度统一 `60rpx`**（特殊：操作切换 `64rpx`）。
3. **按钮字重统一 `500`**。
4. **涨跌色固定**：红涨绿跌，不随系统切换。
5. **主色**：内容页主操作用 `--brand-blue #0071e3`；设置页主操作用 WeUI 绿 `#07c160`。
6. **页面背景**：`#f5f5f7`；卡片白底。

## 13. 实验功能开关（feature flag）
- 开关存储：`wx.setStorageSync('experimentalMode', bool)`；默认 **关闭**。
- 开启方式：**长按底部「设置」tab 满 10 秒**（tab 底部出现蓝色进度条），触发后 vibrateLong + Toast 提示；再次长按可关闭。设置页不再提供开关 UI。
- 关闭时：`pages/setting` 中「实验接口配置」分组整体 `wx:if="{{experimentalEnabled}}"` 隐藏（含内部全部内容）；底部 tabBar 隐藏「分析」页。
- 开启时：显示「实验接口配置」分组，底部 tabBar 恢复 4 栏（总览/持仓/分析/设置）。
- `custom-tab-bar` 组件：`attached` 时按 experimentalMode 过滤分析 tab；`onTabTouchStart`/`onTabTouchEnd` 处理 10s 长按计时（松手即取消）；`applyExperimentalMode(enabled)` 切换、各页 `onShow` 用 `highlight(pagePath)` 按路径高亮（兼容动态索引）；关闭状态下仍停留分析页会自动跳回总览。

> 注：本规范为「描述性」文档，与代码现状一致；后续 UI 微调应以上表 Token 为单一来源，避免散落硬编码。
